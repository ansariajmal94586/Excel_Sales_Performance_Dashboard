# Excel Sales Performance Dashboard

## Project Overview
This project demonstrates the creation of an interactive Sales Performance Dashboard using Microsoft Excel. Raw sales data was transformed into meaningful business insights using data analysis and visualization techniques.

## Tools & Skills Used
- Microsoft Excel
- Data Cleaning
- PivotTables
- PivotCharts
- KPI Cards
- Slicers
- Data Visualization
- Excel Formulas

## Dashboard Features

### KPI Metrics
- Total Sales
- Total Profit
- Target Achievement Percentage
- Top Performing Product

### Visualizations
- Monthly Sales Trend
- Product-wise Revenue Analysis
- Region-wise Sales Distribution
- Salesperson Performance Analysis

### Interactive Features
- Region filter
- Product filter
- Salesperson filter

## Project Workflow

1. Prepared and organized raw sales data.
2. Cleaned date formats for proper Excel analysis.
3. Created PivotTables for different business perspectives.
4. Built KPI cards for important metrics.
5. Created interactive charts using PivotCharts.
6. Added slicers for dynamic filtering.
7. Designed a professional dashboard layout.

## Project Outcome
The dashboard provides a simple way to analyze sales performance, identify top-performing products, compare regions, and evaluate salesperson contribution.
